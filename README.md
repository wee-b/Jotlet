# Jotlet

一个纯客户端的事件记录应用，基于 Electron、TypeScript 和 Vite。无需账号，没有后端或云同步，数据保存在本机。

## 事件与时间线

- 以事件组织事情：事件包含名称、开始时间、可选的结束时间，以及多个进展节点。
- 左侧按所有事件、进行中、已结束和置顶筛选；事件列表展示起止时间、最新进展和节点数量。
- 点击事件，右侧以卡片时间线展示事情的发展。从左向右按发生时间排列，宽度不足时自动换行；支持追加、编辑和删除节点。
- 追加节点时可以填写过去的发生时间。早于事件开始的补录会自动提前开始时间；已结束事件的节点不能晚于结束时间，可以先调整时间或重新开启事件。
- 点击起止时间修改事件时间，点击「标记结束」设置结束时间，也可以重新开启事件。
- 搜索同时匹配事件名称和全部节点内容。事件名称停止输入约 450 ms 后自动保存；节点在点击「保存进展」后保存。删除事件会一并删除全部节点，删除均需确认，暂无回收站。
- `Ctrl / Cmd + N` 新建事件，`Ctrl / Cmd + K` 搜索，`Ctrl / Cmd + S` 立即保存事件名称。

## 导入、导出与迁移

- JSON v2 完整备份包含事件名称、起止时间、置顶状态，以及全部节点的发生、创建和更新时间，适合备份和迁移。
- 兼容旧版 JSON v1。每条旧记录转换为一个事件，原内容成为初始节点，保留原 ID、置顶状态和创建、更新时间。转换不猜测旧记录之间的归属关系。
- 本机仍使用原 `notes.json` 路径，无需手动搬迁。首次写入新版格式前，将旧文件原样保留为 `notes.json.v1.bak`，该迁移副本不会随日常保存轮换。
- UTF-8 Markdown / TXT 每个文件导入为一个事件和一个节点，节点发生时间取文件修改时间，重复导入相同文件可去重。
- 支持多选文件，每批最多 20 MB。任何一个文件验证失败时，整批不写入。相同事件和时间线跳过；同一事件 ID 的不同内容保留为独立事件。
- Markdown 导出按事件组织，并按时间顺序展示每个节点，适合阅读；重新导入时作为一个文字事件，完整恢复请使用 JSON。

在「数据与备份」中查看本地数据文件位置。数据保存在 Electron `userData` 目录下的 `notes.json`，替换前保留上一版 `notes.json.bak`。读取失败时停止编辑，不覆盖原文件；先复制备份，再修复文件并重启。数据文件未加密，请使用系统账户保护隐私。

## 开发

```sh
npm ci
npm start
npm run lint
npm run typecheck
npm test
npm run package
```

测试需要 Node.js 22.6+，使用内置测试运行器。`npm run package` 生成当前平台应用，`npm run make` 生成安装包。

主进程负责受限的本地文件操作，渲染进程通过隔离的 preload 接口访问事件。生产应用阻止网络请求和外部页面导航，内容以纯文本展示。
